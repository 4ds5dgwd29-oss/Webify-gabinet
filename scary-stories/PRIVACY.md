# Polityka prywatności: Szepty po Północy (narzędzie do publikacji)

Ta aplikacja to prywatne narzędzie właściciela kanału YouTube „Szepty po Północy”. Służy wyłącznie do automatycznego wgrywania filmów na ten jeden kanał.

- **Jakie dane:** aplikacja korzysta z uprawnienia `youtube.upload`, żeby wgrywać filmy na kanał właściciela. Nie odczytuje, nie zbiera ani nie przechowuje żadnych danych innych użytkowników.
- **Kto ma dostęp:** tylko właściciel kanału. Token dostępu jest przechowywany jako zaszyfrowany sekret w GitHub Actions i nie jest nikomu udostępniany.
- **Udostępnianie:** żadne dane nie są sprzedawane ani przekazywane osobom trzecim.
- **Usunięcie dostępu:** dostęp można w każdej chwili odebrać na https://myaccount.google.com/permissions.

# Privacy policy

This app is a private tool used only by the owner of the "Szepty po Północy" YouTube channel to upload videos to that channel with the `youtube.upload` scope. It does not collect, store or share any data of other users. The access token is stored as an encrypted GitHub Actions secret. Access can be revoked at any time at https://myaccount.google.com/permissions.
